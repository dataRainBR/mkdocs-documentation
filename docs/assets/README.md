# assets

Esta pasta armazena os recursos visuais utilizados pelo tema e pela documentação:

- `logo.png`: logo DataRain exibido no cabeçalho do site.
- `datarain-logo.ico`: ícone DataRain utilizado como favicon.
- `footer.png`: imagem repetida no rodapé do PDF.
- `documentacao-local.pdf`: PDF completo gerado pelo conversor e publicado junto com o site.

O logo e o favicon são configurados em `theme` no `mkdocs.yml`. O rodapé e o PDF são usados pelo conversor e pelo workflow do GitHub Actions.
